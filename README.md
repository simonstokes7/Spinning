# 🚴 Spinning® Handlebar Mobile Workout

A mobile single-screen cockpit designed for indoor cycling bikes and bike handlebars.

![Handlebar Display](https://raw.githubusercontent.com/simon/Spinning/main/Spinning%20Symbols.jpg)

---

## 🌟 Features

- **📱 Bike Handlebar Optimized:** Single-screen layout with zero vertical scrolling (`100dvh`), high-contrast typography, and sticky touch controls.
- **⚡ Cadence & Zone Tracking:** Displays song BPM, target RPM (half-time cadence for BPM > 110), and official Spinning® Energy Zones (Recovery, Endurance, Strength, Interval, Race Day).
- **🚴 Official Spinning® Movements:** Real-time movement transitions (Seated Flat, Standing Flat, Jumps, Seated Climb, Standing Climb, Running with Resistance, Sprints) with glowing active indicators.
- **📢 Instructor Coaching Cues:** Prominent coaching guidance and music cues visible from bike handlebar distance.
- **⏱️ Live Clock & Screen Wake Lock:** Keeps your phone screen awake throughout the entire ride.

## 🛠️ How to Host on Your GitHub in 3 Steps:

1. **Create Repository:** Create a new repository on [GitHub](https://github.com/new).
2. **Upload `index.html`:** Upload the `index.html` mobile workout file to your repository.
3. **Enable GitHub Pages:** Go to **Settings** &rarr; **Pages** &rarr; select branch `main` &rarr; click **Save**.

Your handlebar workout will be live instantly!
